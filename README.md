A comprehensive job portal plugin for WordPress with company profiles and application management.





== Description ==


Job Portal Pro allows you to create a professional job board on your WordPress site. Features include:





* Custom job post type with full admin integration


* Company profiles with logos and social media


* Advanced filtering by category, type, location, and remote options


* Direct application system that emails employers


* Responsive design that works on all devices


* Easy shortcode implementation





== Installation ==


1. Upload the plugin files to `/wp-content/plugins/job-portal-plugin/`


2. Activate the plugin through the 'Plugins' screen in WordPress


3. Go to Jobs > Add New to create your first job listing


4. Use [job_filters] and [job_listings] shortcodes to display jobs





== Shortcodes ==


* [job_filters] - Display search and filter form


* [job_listings] - Display job listings


* [job_listings posts_per_page="5"] - Limit number of jobs


* [job_listings category="tech"] - Filter by category
